# Atlas benchmark

Owns: public-only benchmark registration, local HTTP import, persisted exploration plans, batched Playwright collection, SQLite/file evidence, Codex SDK planning and specification drafts, contract validation and export.

plan.ts defines the executable contract and planning instructions. browser.ts interprets explicit actions and captures actual responses; it has no model dependency. batch.ts reuses the evidence store and common Codex execution boundary for prepare/collect/analyze. Planning and review each make one explicit provider invocation; collection and plan replay make none. No automatic replan/retry. The caller chooses additional planning/review. Invocation attempts are persisted before the call; returned usage is recorded separately and missing usage is null.

Captured content is untrusted. Meaning belongs to the LLM; schemas, citation/hash checks, credential removal, read-only same-origin enforcement and resource limits belong to code. Keep the initial public-only boundary. A reproduced Chromium redirect bypass requires fetching browser routes without redirect following and stopping redirect responses; direct APIRequestContext requests also use maxRedirects=0. Do not weaken these to pass tests. Planning context, plan and provider accounting are excluded from final report evidence.

Run `bun run verify`: types, Node/Vitest/real Chromium fixtures, UI build. `bun run browser:install` installs the matching Chromium version. Tests use no paid model. Live provider checks must be explicit. ATLAS_DATA_DIR selects private local storage. Case configurations are immutable; replay creates fresh attempts. Opening a store never declares another process interrupted. Existing nullable external reference columns remain for DB compatibility. No schema migration is needed for the new string statuses/source kind.


Evidence projection: evidence.ts uses csv-parse for CSV syntax, scans all records, deduplicates equal bodies, computes bounded structural statistics/examples and exact multiset/query differences. It does not classify column meanings, business types or missing-value sentinels. analyzeAttempt persists an evidence_packet before model invocation. generateReport sends only that packet, not raw bodies, old reports, planning context or usage logs. Original artifacts remain immutable. Source URLs/status excerpts and selected CSV records are exact original quotes; record numbers and UTF-8 byte ranges permit retrieval. Derived statistics cite the packet; http-observed operations still require a direct original citation. A cited packet is recomputed against retained originals at report-save time. Changed source bytes or forged statistics must fail verification.

GET /api/benchmark/attempts/:id/artifacts/:artifactId/body?start=<byte>&end=<byte> returns only the requested original response-body range (max 8192 bytes), with source/body hashes. It enforces the same attempt, hashes and UTF-8 boundaries, preserves BOM, and makes no model or external request. It is an explicit read API; no per-row automatic model loop is added.
